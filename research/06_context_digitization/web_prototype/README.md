# 공군 출입통제 생애주기 Matrix — 승인용 웹 프로토타입

## 상태

이 폴더는 **PowerPoint 제작 전 구성·스토리·시각 밀도를 승인하기 위한 웹 프로토타입**이다. 기존 PPTX는 수정하지 않았으며, 이 웹 결과가 승인된 뒤에만 실제 발표자료로 이관한다.

## 실행

[`index.html`](index.html)을 Chrome 또는 Edge로 열면 별도 설치 없이 동작한다.

발표 준비에는 [`PRESENTATION_RESEARCH_SUMMARY.md`](PRESENTATION_RESEARCH_SUMMARY.md)를 사용한다. 표준의 역할, 군 특화 근거, 최종 산출물, 6단계 발표 대본과 예상 질문을 쉬운 말로 정리했다.

조작 방법:

- 화면 하단 단계 또는 `다음 조명` 클릭
- `←` / `→`: 이전·다음 단계
- `Space`: 다음 단계
- `Home` / `End`: 처음·최종 비전
- `자동 재생`: 6.5초 간격으로 발표 흐름 재생
- `⛶`: 장표 영역 전체화면

URL 끝에 `#step=0`부터 `#step=5`를 붙이면 특정 장면에서 바로 시작한다.

## 한 장 안의 기승전결

| 장면 | 서사 역할 | 조명 요소 | 심사위원에게 남길 판단 |
|---:|---|---|---|
| 1 | 기 — 문제 | 흩어진 신청서·명단·조회·현장판단·장비·로그 | 정보는 있으나 같은 Case로 연결되지 않는다. |
| 2 | 승 1 — 분류 | NIST ABAC 행 | 시스템이 아니라 판단역할로 정보를 정렬한다. |
| 3 | 승 2 — 신뢰 | NISTIR 8112 행 | 값의 존재와 판정 사용 가능성은 다르다. |
| 4 | 전 — 군 보정 | 법령·DoDM/UFC·Local 행 | 일반기준에 군 출입의 관계·검색·장애·사람경계를 보정한다. |
| 5 | 결 1 — 적용 | Core–Military Domain–Site Profile 띠 | 공통 의미를 고정하면서 부대 차이를 통제된 확장으로 보존한다. |
| 6 | 결 2 — 비전 | Digital Context 산출물과 Digital Thread | 신청부터 종결까지 판정과 조치를 같은 근거로 연결·재현한다. |

## 고정된 장표 구조

- 가로축: `신청·등록 → 승인·권한 → 현장확인 → 출입판단 → 집행·예외 → 기록·종결`
- 세로축: `ABAC 판단역할 → 정보 신뢰 → 군 출입 보정 → Digital Context`
- 횡단 통제: `Common Core → Military Access Domain → Site Profile`
- 최종 경계: 정형 정상흐름은 일관 처리하고, 모호성·검색·위협·장애는 근거와 함께 사람에게 인계

## 시각 설계 의도

- 동일한 Matrix를 유지해 관객이 매 장면마다 구조를 다시 학습하지 않게 한다.
- 활성 행만 청색 또는 군 특화 황색으로 조명하고 나머지는 맥락이 보일 정도로만 남긴다.
- 표준명은 행의 근거 배지에 제한하고, 각 셀은 변수명 대신 판단 질문으로 표현한다.
- 시작 장면은 끊김과 단절을, 최종 장면은 모든 열을 관통하는 Digital Thread를 보여준다.
- 최종 장면에서도 Level 2와 `공군 공식표준 확정 아님`을 유지해 비전과 증거한계를 동시에 제시한다.

## 승인 후 이관 원칙

1. 장표의 기하구조와 6단계 조명 순서를 PowerPoint에 그대로 유지한다.
2. 웹의 설명 패널은 발표자 notes로 옮기고 본문 장표에는 넣지 않는다.
3. 클릭 빌드는 `ABAC → 신뢰 → 군 특화 → 적용범위 → Digital Context` 순서만 사용한다.
4. 정적 PDF 제출본에는 최종 통합 장면을 사용한다.
5. 세부 객체·필드·스키마는 부록으로 분리한다.

## 이번 승인에서 볼 항목

- 생애주기 가로축이 직관적인가
- ABAC에서 다음 기준으로 발전하는 이유가 자연스러운가
- 군 특화가 일반표준의 단순 나열이 아니라 보정 논리로 보이는가
- Core–Domain–Site가 ‘무엇을 획일화할지’에 답하는가
- 마지막 장면에서 디지털화 성공의 비전이 충분히 느껴지는가
- 셀의 정보량이 발표 화면에서 읽을 수 있는 수준인가
